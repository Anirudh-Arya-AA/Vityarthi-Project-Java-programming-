## Project Description
This is a simple Java project that calculates the total marks, average marks, and grade of a student based on marks entered by the user.

## Features
- Takes student name as input
- Takes marks of three subjects
- Calculates total marks
- Calculates average marks
- Displays grade

## Requirements
- Java JDK 17 or above

## Compile
javac Main.java

## Run
java Main

## Sample Output
Student Name: Nyasha
Total Marks: 270
Average: 90.0
Grade: A
